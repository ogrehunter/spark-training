# Pelatihan Pengolahan Data dengan Spark

**Kementerian Keuangan Republik Indonesia — Badan Pendidikan dan Pelatihan Keuangan**

**Total:** 35 JP (35 JP tatap muka)

## Tujuan Pembelajaran

Setelah mengikuti pelatihan, peserta mampu menggunakan Apache Spark untuk melakukan pengolahan, integrasi, transformasi, analisis, dan optimasi data guna mendukung kebutuhan pengelolaan data dan pengambilan keputusan berbasis data di lingkungan organisasi.

## Kebutuhan Strategis

Pelatihan ini diperlukan untuk meningkatkan kapasitas SDM DJP dalam mengelola dan menganalisis volume data yang semakin besar dan kompleks guna mendukung pengambilan keputusan berbasis data. Pemanfaatan Apache Spark memungkinkan pengolahan data dari berbagai sumber secara terdistribusi dengan kinerja yang lebih cepat dan efisien dibandingkan metode konvensional, sehingga mendukung kebutuhan integrasi data, transformasi data, dan analisis data dalam skala besar. Kompetensi penggunaan Apache Spark diharapkan dapat memperkuat pengembangan ekosistem data modern, meningkatkan kualitas pengelolaan data, dan mendukung pelaksanaan transformasi digital di lingkungan DJP.

## Sasaran

ASN di lingkungan Kementerian Keuangan khususnya bagi Jabatan Fungsional Pranata Komputer dan pegawai yang bertugas dalam pengelolaan, integrasi, transformasi, dan analisis data yang memerlukan pemanfaatan platform pengolahan data terdistribusi menggunakan Apache Spark.

### 1. Konsep Dasar Apache Spark (5 JP)

**Standar kompetensi:** Menjelaskan konsep *big data* dan arsitektur Apache Spark sebagai platform pengolahan data terdistribusi.

1. Menjelaskan karakteristik dan tantangan pengelolaan *big data*.
2. Menjelaskan arsitektur dan mekanisme kerja Spark.
3. Menerangkan komponen utama Apache Spark.
4. Menerangkan konsep *Lazy Evaluation*, *Directed Acyclic Graph* (DAG), serta konsep *Transformations vs Actions*.

### 2. Spark Data Processing (7 JP)

**Standar kompetensi:** Memproses data menggunakan Apache Spark.

1. Menerangkan konsep Apache Spark dan SparkSession.
2. Memproses dan mengkonfigurasi SparkSession untuk pengolahan data.
3. Menggunakan Spark DataFrame dari berbagai sumber data.
4. Melaksanakan filtering dan sorting data menggunakan Spark DataFrame.
5. Memproses pengolahan data dasar menggunakan DataFrame.

### 3. Data Integration dan Data Transformation (7 JP)

**Standar kompetensi:** Melaksanakan integrasi dan transformasi data menggunakan Apache Spark.

1. Melaksanakan transformasi data menggunakan operasi DataFrame.
2. Memproses integrasi data dari berbagai format, seperti TXT, CSV, JSON, Parquet, dan ORC.
3. Memproses Apache Spark dengan sumber data eksternal, termasuk database relasional menggunakan JDBC dan database NoSQL.
4. Memproses penggabungan data dari berbagai sumber menggunakan operasi join dan union.
5. Memproses data terstruktur dan semi-terstruktur.
6. Memproses penyiapan dataset untuk kebutuhan analisis.

### 4. Spark SQL dan Data Analytics (7 JP)

**Standar kompetensi:** Memproses analisis data menggunakan Spark SQL.

1. Menjelaskan konsep PySpark dengan operasi dan fungsi dasar.
2. Menggunakan Spark SQL dan PySpark untuk analisis data.
3. Memproses *query* pada *dataset* berskala besar.
4. Melaksanakan agregasi dan perhitungan statistik.
5. Memproses hasil analisis data untuk kebutuhan bisnis.

### 5. Spark Structured Streaming (4 JP)

**Standar kompetensi:** Memproses data secara *realtime* menggunakan Spark Structured Streaming.

1. Menjelaskan konsep *Structured Streaming*.
2. Memproses integrasi sumber data *streaming*.
3. Menerapkan *Window Operations* dan *Watermarking*.
4. Menggunakan *output* hasil pemrosesan *streaming* melalui berbagai *output sink*.

### 6. Spark Optimization dan Best Practices (5 JP)

**Standar kompetensi:** Menerapkan teknik optimasi pengolahan data pada Apache Spark.

1. Menjelaskan faktor yang memengaruhi kinerja Spark.
2. Melaksanakan optimasi *query* dan proses transformasi.
3. Memproses partisi data.
4. Menerapkan praktik terbaik pengolahan data menggunakan Spark.
5. Melaksanakan pemantauan dan menganalisis *job* Spark.
